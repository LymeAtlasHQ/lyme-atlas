# Roadmap

This repository tracks the broader LymeWire ecosystem: open science, patient resources, evidence standards, and cross-product direction.

## Phase 1 - Foundation

Status: done

- Create GitHub account and repositories.
- Define mission and principles.
- Establish LymeWire as the public product brand.
- Keep LymeAtlasHQ / Lyme Atlas as legacy project and repository naming where needed.

## Phase 2 - Scientific Knowledge

Status: active

- Organize evidence-based Lyme and tick-borne illness resources.
- Review diagnostic methods and uncertainty.
- Review treatment guidelines and disagreements.
- Track publication databases and key PubMed records.
- Track ClinicalTrials.gov studies.

## Phase 3 - LymeWire AI

Status: active in `LymeAtlasHQ/lyme-ai`

- Telegram MVP.
- PubMed Evidence Cards.
- Guideline comparisons.
- Treatment claim review.
- Care navigation.
- Calm mode for panic-heavy health questions.
- Doctor brief generation.

## Phase 4 - Product Ecosystem

Status: planned

- LymeWire web app.
- LymeWire iOS app.
- LymeWire Android app.
- User-owned symptom timeline.
- Doctor brief export.
- Source-backed Knowledge Wire retrieval.

## Phase 5 - Operations and Collaboration

Status: planned

- GitHub Issues as engineering backlog.
- Linear project mirror where available.
- Floot dashboard for sales, partnerships, revenue, and leads.
- Weekly research scan automation.
- Contributor and tester onboarding.

## Phase 6 - Trusted Health Data Integration

Status: future, privacy/legal dependent

- Consent-driven imports only.
- Encryption, audit logging, deletion/export rights.
- Turkey, UK/EU, and US legal review before durable medical storage.
- Wearable and user-uploaded document paths before official health-system integration.

## Current focus

1. Lock LymeWire logo across public surfaces.
2. Test Telegram MVP with first users.
3. Build the first web app prototype.
4. Add shared Wire router and Knowledge Wire retrieval.
5. Prepare iOS/Android path after web prototype works.
