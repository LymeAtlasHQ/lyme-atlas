# 🧬 Lyme Atlas

> Open science initiative for Lyme disease research, education, and AI-assisted knowledge systems.

## Vision

Building the world's most trusted, evidence-based knowledge platform for Lyme disease.

## Mission

Provide free, continuously updated, scientifically grounded information for patients, clinicians, and researchers.

## Core Principles

- Evidence before opinion.
- Transparency.
- Open science.
- Continuous improvement.
- Patient-centered.
- AI-assisted, human-reviewed.
